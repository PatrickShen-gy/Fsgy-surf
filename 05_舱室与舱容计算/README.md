## 输入与独立计算

读取02的`CAD_mesh/01_展示模型/compartments.npz`与`compartments.json`，而不是把钢材实体当成可装载空间。包含5个货舱、10个左右边舱、5个双层底空间、1个机舱包络、2个艏艉空间。不改写02。

对每个闭合舱室计算：

- 满几何容积、容积中心CGX/CGY/CGZ、纵向范围及底高/顶高。
- 201档基本液位，另加折角高度和局部极值搜索点：液位、体积、容积中心、自由液面面积与形心惯性矩。
- 0—100%、间隔2%的51档几何装载率，用体积反求液位，共1173组。
- 假设液体的自由液面惯性矩IT、IL，以及水密度1.025t/m³对应的FSM诊断值。
- 部分充液过程的最大IT及对应液位、装载率。采用采样和局部搜索估计，未宣称严格全局解析极值。

液面默认零横倾、零纵倾的水平面；液位是基线以上的绝对z坐标。部分体积由三角面裁切和有向四面体积分，液面面积/惯性矩由交线格林积分得到；装载率反求使用Brent法。

```text
fill_fraction = volume / full_geometric_volume
FSM = liquid_density * IT                  # t/m³ × m⁴ = t·m
free_surface_correction = sum(FSM) / DISP   # m，后续重量/稳性阶段使用
```

IT绕过自由液面形心、平行x轴的纵向轴计算，IL绕横向轴计算。压满的封闭舱与空舱实际FSM均设为0；手册表中FSM是最大值口径，两者不能混用。货舱曲线中的IT只是其装液体时的几何属性，粮食、矿砂等散货不直接套用液体FSM，实际堆形/安息角/密度仍由工况设置。

现有舱室几何继承了02的8mm横/纵隔板退让，但尚未全部按外壳内表面、内底实体、骨架等修剪，故不把本阶段几何体积称为已扣尽结构的净舱容，也不再次无条件扣除一遍板材。

## PDF提取与对应关系

第81—83页提取84个位置记录，第84—86页提取83个独立舱容记录。原始字段包括型/净容积、重心、最大液面惯性矩、最大FSM、密度、Reduction和FILL表头。保存原行、来源物理页码及文件SHA256，不重写参考数据。

提取按页面文字坐标重组同行，处理CGX/负CGY粘连以及字段换行。8个类别的体积、净容积及FSM合计与印刷合计均在累计舍入范围内一致。

| 覆盖状态 | 数量 | 含义 |
|---|---:|---|
| 货舱近似几何 | 5 | 同号货舱可作差异对照，边界细节尚不完整 |
| 部分几何 | 10 | 实际左右压载舱涉及边舱、双层底及其它边界，不能直接用单个边舱代替 |
| 端部包络 | 2 | 艏/艉包络还包含其它空间，不等于FPT/APT实际尖舱 |
| 仅参考数据 | 67 | 尚无独立计算几何，保留PDF数据供后续明确选用 |

不能简单用“左边舱+一半双层底”代替真实压载舱：还缺管弄、中线分隔、上部油舱/隔离舱等边界，错误合并也会改变自由液面惯性矩。机舱/双层底/端部空间的填充曲线仅作几何诊断，不代表这些空间可以整体加注。

保留的参考表差异：

- CLS在位置表中存在，容量表未列独立数据，保持null而不是补零或镜像CLP。
- 四个柴油舱位置表密度为0.86，容量表为0.85；两者均保留。后续按明确工况选密度。
- Grain Load的Reduction表头为1，但VNET/VOLM约0.998；不使用`1-Reduction`自动推算净舱容。
- IYMAX印刷为整数，而FSM保留一位小数，不能强求每行`FSM=rho*印刷IYMAX`严格相等。
