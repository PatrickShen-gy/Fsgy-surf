## 方程与有限角度处理

固定横倾phi，将原船体坐标旋转到计算坐标：

```text
y' = cos(phi)*y + sin(phi)*z
z' = -sin(phi)*y + cos(phi)*z + datum_shift
waterplane: z' = a + b*(x-xref)
pitch = atan(b)
```

对z增加纯坐标平移，避免04静水力系数在数值T=0处的奇点；体积、力臂和物理几何不改变。

在各横倾角，联立恒重量与世界水平纵向投影对齐：

```text
rho*(VOLM + t*WSA) = W
(Bx' - Gx') + b*(Bz' - Gz') = 0
```

因此每个角度均自由调整水面高度和纵倾，不是固定中吃水后直接旋转船体，也不是简单令LCB=LCG。采用水线形状导数构造准牛顿雅可比；一阶外板湿表面积导数未放进雅可比，但以实际修正后的质量残差迭代收敛。

GZ按选定横倾侧方向表示正恢复力臂：

```text
GZ_fixed = side_sign * (By' - Gy')
FSMOM = FSM * sin(theta)
DGZ = FSMOM / W
GZ = GZ_fixed - DGZ
```

theta是图上的非负角度；PS左舷下沉时phi=theta，SB右舷下沉时phi=−theta。包含该工况TCG，故0°时的GZ可能不为零。

自由液面采用手册同一等效虚升/正弦修正口径，未重新计算每个液舱随大倾角变化的液面和液体重心。浮心保持型线网格口径，18mm仅用于排水体积一阶修正；外板完整偏置仍是模型限制。

## 角度、面积与稳性范围

- 0—90°每2.5°，另加PDF的12°；95—180°每5°，共56档。
- PDF工况表只提供0、10、12、20、30、40、50、60、70°，大于70°不外推参考数据。
- 面积用弧度积分，采用采样曲线的PCHIP解析原函数。导出0—30°、0—40°、30—40°原始面积；尚未按实际进水角截断。
- 峰值和稳性消失角由采样曲线PCHIP近似定位，受2.5°/5°采样步长影响，不代表精确连续几何极值。
- 稳性消失角AVS为首个正GZ区间之后进入负GZ的零点。输出名称明确为`AVS_sealed_hull_deg`，不能直接替代完整船型的稳性范围。
- GM另由±0.1°的GZ中心差分斜率计算，用作07初稳性结果的独立数值对照；全表最大差约0.00429m。
