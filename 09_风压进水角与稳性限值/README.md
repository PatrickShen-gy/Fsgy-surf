# 09 风压、进水角与稳性限值

运行：`python stability_criteria.py`。查看：[HTML对照](output/criteria_verification.html)。依赖07的浮态与08的GZ/姿态结果。

本阶段按所给手册23—26、73—79页及逐工况汇总页提取条件，计算39工况的基本稳性指标、天气面积比、4个开口的水面相交角，并保存零纵倾参考限值。原始条件与PDF来源指纹保存在`output/reference`。

## 输出

| 文件 | 内容 |
|---|---|
| `criteria_results.json` | 全部工况的指标、开口、天气参数及诊断KG限值 |
| `criteria_verification.csv` | 39×7项基本稳性/天气指标对照 |
| `flooding_angles.csv` | 39×4个开口的进水角 |
| `weather_results.csv` | 风压臂、横摇角、面积与敏感性 |
| `case_KG_limits.csv` | 当前浮力曲线固定条件下的基本稳性KG限值诊断 |
| `reference/KG_limit_zero_trim.csv` | 手册85点零纵倾参考限值；仅保存，不冒充独立计算 |

## 方法与边界

风压采用手册504N/m²，风面积及一阶矩按手册吃水表插值。超出表范围会标记。开口使用手册肋位、横向位置和高度，在08每个固定横倾、自由纵倾姿态下计算水面余量并求零点。首次甲板封顶接触与开口进水角是不同量，分别报告。

天气面积使用当前GZ及近似镜像的风上侧曲线。按手册文字主计算取`r≤1`；同时输出不截断r的敏感性结果。LD00主计算b/a约1.746，取消r上限约0.992，手册为0.979。这一差异原样保留，不以改动参数来拟合手册。天气判定同时检查稳态风倾角条件与面积比。

没有求得第二阵风交点时输出null，不将90°伪称为交点；面积积分仍受50°及进水角等上限约束。基本KG限值冻结当前浮力GZ曲线，仅求六项基本指标，未包含天气限值，不能与完整MAXKG表视为同一量。

由于02缺少完整艉楼、艏楼和舱口围板储备浮力，当前进水、天气和高角度限值属于主船体诊断。程序保留`full_vessel_geometry_complete=false`。
