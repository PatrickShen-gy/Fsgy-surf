# 10 纵向剪力与弯矩

运行：`python longitudinal_strength.py`。查看：[HTML对照](output/longitudinal_verification.html)。输入为02网格、05舱位目录、06逐项载荷与07平衡水面。

## 方法

1. 从手册333页读取17项空船质量和重心，逐工况读取06载荷。分布区间在代码`LIGHT_SPANS`及舱位目录中显式给出；区间内以非负指数分布守恒各项质量和纵向质量矩，无区间物资以相邻单元分配的点载荷近似。
2. 手册空船分项的合成LCG为79.296432m；统一平移0.00356763m，与06采用的79.30m打印重心对齐。该操作仅消除输入舍入差，不拟合PDF剪力、弯矩或分布。
3. 按07水面对02网格切片，沿船长用单元两端及中点Simpson积分浮力。整体浮力质量因子沿用07的一阶外板口径，浮心保持型线口径。
4. 对重量减浮力积分剪力和弯矩；包含纵倾下轴向重力与不同载荷高度形成的力矩。端部残差原样记录，不通过线性修正强行闭合。
5. 每工况16站、共624站与PDF对照。15页完好状态限值按肋位插值，t/t·m按g=9.81转换为kN/kN·m，仅在原表肋位范围内判断。

## 输出与结果

| 文件 | 内容 |
|---|---|
| `longitudinal_results.json` | 各工况分布曲线、极值、站位对照、端部闭合 |
| `longitudinal_data.npz` | 公共船长网格及39工况SF/BM数组 |
| `station_verification.csv` | 624站位对照 |
| `closure_checks.csv` | 质量、重心、切片体积及端部闭合 |
| `distribution_assumptions.csv` | 每项载荷来源、假设区间、质量矩残差 |
| `reference` | 原始空船分项、限值及对照表缓存 |

当前剪力平均绝对差约39.06t，弯矩约666.66t·m；端部剪力最大残差约1.14×10⁻¹¹t，弯矩约1.62t·m。端部闭合说明积分与平衡基本自洽，不代表中间分布已复现手册。

空船及舱载荷分布形状仍有明确假设，未实现手册的局部舱壁/斜板CORR剪力修正。原表FR34的-950000负弯矩限值与FR220的-400“POSITIVE”剪力限值保留原值并标为源表疑点；不擅自修正。当前输出不能视为完整纵强度审批结论。
