# 35000DWT 母型出图模板

本模板依据用户提供的两份 DWG 及 `cases/example` 中的对应 DXF 提取。已用 AutoCAD 内核只读导出两份 DWG，与 DXF 核对实体类型和数量一致；来源文件名及 SHA-256 保存在 `template.json` 的 `sources` 中。

总布置和舱容版式另参考 `cases/example/35000DWT散货船总布置图_2010VER.dxf` 和母型资料中的 `DC081210,103,001舱容图-A.dwg`。舱容 DWG 已只读导出检查，总布置和舱容来源摘要分别保存在 `general_arrangement`、`capacity_plan` 设置中。

模板包含型线、典型横剖面、总布置及舱容图版式。运行出图后，在算例的 `results/13/index.html` 查看图纸。

## 模板文件

| 文件 | 用途 | 编辑方式 |
|---|---|---|
| `template.json` | 型线图布局、图框、型值表、标题栏、字高、颜色、参考尺度及剖面映射控制点 | 文本编辑器 |
| `typical_section_details.dxf` | 从原剖面提取的纵骨、开孔、双层底构件、舷侧结构、甲板梁拱和舱口围板线条 | CAD |
| `general_arrangement_details.dxf` | 母型侧视上部结构、起货设备、居住甲板及上甲板参考细节 | CAD |

剖面模板 DXF 以 **CL/BL 为原点，单位 m**。总布置模板按 `profile/accommodation/deck` 图层分别归一到各视图基准点，原点保存在 JSON 的 `views` 中；不同视图的图面 Y 不代表同一个船体高度。最终出图转为 mm。剖面弧线按约2mm离散；总布置线条适度简化、去重，省去细小零件和旧尺寸、旧图框。

## 配色、字体和比例

模板按 CAD 深色背景设置亮色：蓝色型线、绿色甲板/货舱、青色中心线/边舱、品红结构/舱壁、黄色文字及标注，白色外形。颜色在 `palette`、`styles` 中修改，SVG 背景为 `#10141c`。

生成端使用 Windows 等线 `Deng.ttf`，覆盖中文、英文和 m²、m³ 等符号。中文和中英文混排标注按真实字形内外环输出轮廓，避免字体缺失及混排漏笔画；原始 TEXT 保存在关闭的 `TEXT_EDITABLE` 图层。SVG 所有文字均为轮廓，不依赖查看端字体。改字后应由程序重绘，以保持原文与轮廓一致。

主图模型空间为1:1，尺寸单位mm。典型剖面的局部图单独注明2:1或1.5:1；舱容及重心采用m³、m。

## 型线图模板

保留原图的整体布局：左上型值表，中上横剖线，右上主要尺度，中部纵剖线，下部半宽水线，右下标题栏。补充上甲板边线、艏艉楼边线、舷墙顶边线和 WL 高度注释；艏艉楼/舷墙参考线取母型型值表并缩放，不参与静水力。

`lines` 中各位置和字高以母型 m 制图面坐标指定，随目标主尺度统一调整图幅位置；船体曲线仍按目标船实际尺寸绘制，不作图面变形。

- `frame`：图框 `[左, 下, 右, 上]`。
- `profile_origin`、`plan_origin`、`body_origin`：三个视图的基准点。
- `table_origin`：型值表左上角；`table_width/height`：表格宽、高。
- `particulars_origin`、`title_block`：主要尺度与标题栏位置。
- `waterlines_m`、`buttocks_m`：参考水线高度和纵剖半宽，分别随型深、型宽缩放；设计吃水和结构吃水另行加入。
- `view_text_height`、`grid_text_height`：视图标题与网格文字字高。

型值表每次从目标船横剖面求交生成，包含站号、X、平底半宽、各水线半宽、甲板半宽、中线高度和甲板高度。表内及图中尺寸为 mm，另存 `offsets.csv` 的数值为 m。空白位置用 `-` 表示该水线没有切入该站船体。

## 典型横剖面模板

参考型宽 28.8 m、型深 14.6 m；双层底高 1.75 m、边舱宽 1.3 m、内舷半宽 13.1 m、上部货舱半宽 10 m。参考梁拱为 0.5 m，围板顶高于梁拱顶 1.75 m。

程序按 `source_y_knots_m`、`source_z_knots_m` 分段映射参考线条，使双层底、内舷、斜壁及甲板控制位置跟随当前 `compartments` 设置。横向控制点依次为中线、上部货舱边、内舷、外舷、图外范围；垂向控制点依次为图下范围、基线、内底、下层舷侧纵桁、斜壁起止点、甲板、梁拱顶、围板顶、图上范围。

母型构件示意用于全宽的平行货舱段。若所选剖面位于机舱或变剖面区，程序使用当前模型的船壳和分舱边界；不会把全宽货舱的构件直接放入变剖面。

参考纵骨、开孔和围板只表达图面结构，不写回 02 网格，也不增加钢结构质量或改变舱容。外板及主分舱计算继续使用现有模型。改变主尺度后，构件示意随模板映射，构件实际规格仍需结构设计确定。

横剖面另含货舱净剖面积、内底板/纵骨/斜壁引线，以及舭部连接、双层底中桁、顶边舱三幅局部图。局部图截取同一套参考构件，不另造结构尺寸。

## 总布置模板

`general_arrangement` 定义图框、侧视、居住甲板、上甲板、内底以上水平剖面及标题栏位置。甲板室、起货设备和居住甲板参考母型；船体、主舱壁与分舱边界从当前模型绘制。

侧视和上甲板参考几何按 `source_boundaries_m` 与当前主舱壁坐标进行纵向分段映射，使舱口和设备布置跟随舱段变化。宽度和高度分别随型宽、型深缩放。居住甲板的独立图面位置按图幅比例调整。参考布置只用于图示，不自动增加上层建筑浮力、重量或房间载荷。

## 舱容模板

`capacity_plan` 参考母型舱容图的“左侧三视图、右侧典型剖面与舱容表”版式。视图包括中纵剖面、半型深水平剖面、半双层底高处剖面和3号/1号货舱横剖面。

表内的空间编号、用途、满舱容积、LCG、TCG、KG **直接来自02当前封闭分舱模型**，另存 `capacity_plan.csv`。因此只运行 `drawings` 就可出舱容图，不必先计算05的部分装载曲线。

当前共有5货舱、10边舱、5双层底空间、机舱与艏艉空间。母型图中的更多小舱并未全部建立，不移植其旧舱容；用途未指定的空间保持“未指定”。容积为对应几何空间包络值，图示甲板室和设备不改变这些数值。

## 启用与调整

`case.json` 顶层可加入：

```json
"drawings": {
  "template": "mother_35000",
  "types": ["lines_plan", "typical_section", "general_arrangement", "capacity_plan"],
  "structure_details": true
}
```

`types` 省略时输出全部四图。`structure_details: false` 关闭参考构件，仅保留模型边界；`template: "simple"` 恢复原简化版式。`stations_m`、`waterlines_m`、`buttocks_m`、`section_x_m`、`plan_z_m` 仍可按目标船坐标指定。

在项目根目录运行：

```powershell
python main.py --case 34000t --tasks drawings
```

结果位于 `cases/34000t/results/13`。`revision` 可指定其他子目录；省略时使用 `results/13`。修改模板后会更新第13工序。当前LOA可独立控制，站号、艏艉参考边线及总布置AP/FP映射会随几何同步更新；性能设计输入和复算值在主参数表中分别列示。
